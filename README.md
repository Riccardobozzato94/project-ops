# ProjectOps

Un report settimanale non serve a dire che siamo occupati. Serve a dire cosa è chiuso, cosa non ha un responsabile e cosa deve succedere dopo.

Questa pagina prende cinque attività di esempio, conta i punti completati e le attività senza owner, e scrive una bozza. La bozza diventa report solo quando la firmi con nome e data.

**Apri lo strumento:** https://riccardobozzato94.github.io/project-ops/

## Perché è pubblico

È un esempio piccolo e ispezionabile di un principio che applico ai progetti veri: l'output di un sistema resta una bozza finché una persona non lo approva. Qui non c'è modello, API o segreto: solo HTML e JavaScript leggibili.

## Cosa non fa

- Non invia email e non salva nulla su un server.
- Non usa dati reali: attività, nomi e numeri sono inventati.
- Non sostituisce un piano di progetto: produce un report, non una decisione.

Parte degli [strumenti pubblici](https://riccardobozzato.com/chi-sono) di Riccardo Bozzato.
