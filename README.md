# ProjectOps

Trasforma una lista di attività in un report settimanale con avanzamento, attività senza responsabile e prossimo passo. Il report riporta chi ha firmato e la data.

**Apri lo strumento:** https://riccardobozzato94.github.io/project-ops/

Nessun account, nessuna installazione, nessun costo. Tutti i dati sono di esempio e nessun invio è automatico.
